Deques

Builder · ages 10+

A deque is a line you can add to or remove from at both ends. To find the biggest number in every window, keep only the numbers that might still win and drop the smaller ones behind a bigger newcomer.

Play this lesson

How it works

  1. deque ← empty (holds positions)
  2. for each number n
  3. drop from the BACK while the back is ≤ n
  4. add n at the back
  5. drop from the FRONT if it left the window
  6. the front is the window maximum
  • EndsBoth open
  • TimeO(n)
  • Used forWindow maximum

Deques Builder

Candidates in a queue

You need 9 number cards and a strip of paper · Time 15 minutes

  1. Lay 9 cards in a row. We want the biggest in every 3 in a row.
  2. Keep a short queue of candidates. A new card removes any smaller cards from the back, then joins the back.
  3. If the front card has slid out of the window, remove it.
  4. The front card is the biggest in the window. Write it down.

Think about it. Why can a smaller card behind a bigger one never be the biggest again?
