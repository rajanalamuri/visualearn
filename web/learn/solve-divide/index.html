Divide and conquer

Builder · ages 10+

Split a big problem into two halves, solve each half the same way, then combine the answers. Here the problem is the best run of numbers in a row. It is in the left half, in the right half, or across the middle.

Play this lesson

How it works

  1. solve(range): if one number, that is the answer
  2. split the range in the middle
  3. best of the left half
  4. best of the right half
  5. best run straddling the middle
  6. answer ← the biggest of the three
  • StepsSplit, solve, combine
  • TimeO(n log n)
  • Smallest pieceOne number

Try it on paper

Divide and conquer Builder

Halve and combine

You need Paper and 8 numbers, some negative · Time 15 minutes

  1. Write 8 numbers, some below zero. We want the biggest total of numbers next to each other.
  2. Split into two halves of 4. Find the best run in each half the same way (split again until one number).
  3. Now find the best run that crosses the middle: the best run ending at the middle, plus the best run starting after it.
  4. The answer is the biggest of the three.

Think about it. Why do you need the crossing case? What would you miss without it?
