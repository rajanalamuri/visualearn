Treaps

Advanced · ages 13+

A treap is a search tree with a random priority on every node. Keys keep the order left to right. Priorities keep the biggest at the top. The randomness keeps the tree bushy, even when the keys arrive in order.

Play this lesson

How it works

  1. add the node like a normal search tree, by key
  2. give it a random priority (p)
  3. while its priority is higher than its parent's:
  4. rotate it above its parent
  5. search order and priority order both hold
  • Order byKey (left < right)
  • Heap byRandom priority
  • HeightAbout log n, by luck

Try it on paper

Treaps Advanced

Keys and dice

You need Paper, a pencil, a dice or number cards for priorities, and 7 numbers in order · Time 20 minutes

  1. Write 7 numbers in increasing order. Give each a random priority (draw numbers from a hat).
  2. Add them to a search tree one at a time by key. A plain tree would be a stick.
  3. After adding a node, if its priority is bigger than its parent's, swap their places by rotating, and repeat.
  4. Compare the height of your tree with a stick of 7.

Think about it. Why does random priority make the tree behave as if the keys had arrived in random order?
