Bitmask DP

Advanced · ages 13+

A bitmask is a row of 0s and 1s that shows which jobs are taken. Store the cheapest cost for every mask. Build each answer from a smaller mask plus one more job.

Play this lesson

How it works

  1. best[000] ← 0 (no jobs taken)
  2. for each mask, smallest first
  3. worker ← the number of jobs taken
  4. for each job j in the mask: best[mask without j] + cost[worker][j]
  5. best[mask] ← the smallest of those
  6. the answer is best[111]
  • Masks2ⁿ states
  • EachOne cell per set
  • Good forSmall sets (about 20)

Try it on paper

Bitmask DP Advanced

Jobs and workers

You need A 3 by 3 table of costs, paper and a pencil · Time 20 minutes

  1. Write a 3 by 3 table: the cost of each worker doing each job.
  2. List all 8 subsets of jobs as 000, 001, … 111 (1 means the job is taken).
  3. For each subset, the number of 1s tells you how many workers are done. Try removing each job in turn: previous best + that cost for the next worker. Keep the smallest.
  4. The cost for 111 is the cheapest way to give every worker a different job.

Think about it. How many ways are there to give 20 workers 20 different jobs? How many masks are there?
