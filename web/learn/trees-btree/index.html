B-trees

Advanced · ages 13+

A B-tree keeps several numbers in each node, so the tree is short and wide. Databases love that. When a node gets too full it splits, and the middle number moves up.

Play this lesson

How it works

  1. walk down to the leaf where the number belongs
  2. put the number in that leaf, in order
  3. if the node now holds 3 numbers: split it
  4. the middle number moves up to the parent
  5. if the root splits, the tree grows taller
  • Keys per nodeUp to 2 here
  • All leavesSame depth
  • Used forDatabases, file systems

Try it on paper

B-trees Advanced

Boxes of numbers

You need Paper, a pencil and 7 numbers · Time 15 minutes

  1. Draw a box that can hold at most 2 numbers. Add numbers in order into the right place.
  2. When a box would hold 3, split it: the middle number goes up into a new box above, and the other two become its children.
  3. Keep adding. Every time a box fills to 3, split it.
  4. Check: are all the bottom boxes on the same level?

Think about it. Why does a B-tree never get lopsided the way a plain search tree can?
