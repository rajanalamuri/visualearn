Minimum spanning trees

Advanced · ages 13+

Join every town with the cheapest total road. Sort the roads from cheapest to dearest. Take a road only if it joins two towns that are not already connected, so it never makes a loop.

Play this lesson

How it works

  1. sort the roads, cheapest first
  2. for each road
  3. if its ends are in different groups:
  4. take the road, join the groups
  5. else skip it (it would make a loop)
  6. total of the taken roads
  • ResultCheapest way to join all
  • TimeO(roads log roads)
  • UsesUnion-find

Try it on paper

Minimum spanning trees Advanced

Cheapest network

You need Paper, a pencil and a small map with road costs · Time 15 minutes

  1. Draw 6 towns and 8 roads with different costs.
  2. List the roads from cheapest to dearest.
  3. Go down the list. Draw a road in colour only if it does not close a loop with roads already coloured.
  4. Stop when all 6 towns are joined (5 roads). Add up the costs.

Think about it. Why is it safe to always take the cheapest road that does not close a loop?
