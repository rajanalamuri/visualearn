Roadmap · Dynamic programming

Fewest coins

Builder · ages 10+

Solve the small problems first and write each answer in a table. Then build each bigger answer from answers you already wrote down. Nothing is worked out twice.

Play this lesson

How it works

  1. table[0] ← 0 coins
  2. for each amount a from 1 up
  3. try each coin k: table[a − k] + 1
  4. table[a] ← the smallest of those
  5. the answer is the last table entry
  • IdeaReuse answers
  • Table sizeOne per amount
  • BeatsBiggest-coin-first

Try it on paper

Fewest coins Builder

The coin table

You need Paper, a pencil and three kinds of coins, such as 1, 4 and 5 (real or drawn) · Time 15 minutes

  1. Draw a row of 11 boxes, numbered 0 to 10. Write 0 in box 0.
  2. For box 1: take away each coin that fits, look at the box that is left, and add 1. Write the smallest.
  3. Do the same for box 2, box 3, and on up to box 10. Always look back at boxes you have already filled.
  4. Check box 8. Is it what you get by grabbing the biggest coin first?

Think about it. The table made every answer from smaller answers. Why is that quicker than trying every possible handful of coins from scratch?
