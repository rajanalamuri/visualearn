Edit distance

Builder · ages 10+

How many edits turn one word into another? An edit is adding, removing or changing one letter. A table stores the cheapest way to turn each start of one word into each start of the other.

Play this lesson

How it works

  1. table[i][0] ← i; table[0][j] ← j
  2. for each letter pair (i, j)
  3. if the letters match: copy the cell up-left
  4. else: 1 + the smallest of up, left and up-left
  5. the last cell is the distance
  • EditsAdd, remove, change
  • TimeO(m × n)
  • Used forSpell-checkers

Try it on paper

Edit distance Builder

Fix the word

You need Two short words, paper and a pencil · Time 15 minutes

  1. Pick two words like CAT and CUT. Draw a grid with a blank row and column first.
  2. The first row counts 0, 1, 2, … and so does the first column.
  3. Each cell: if the letters match, copy the cell up and to the left. If not, add 1 to the smallest of the cell above, the cell to the left and the cell up-left.
  4. The last cell is the fewest edits.

Think about it. Why does the distance never exceed the length of the longer word?
