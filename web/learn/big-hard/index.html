Easy and hard problems (P vs NP)

Builder · ages 10+

Some problems are quick to check but seem slow to solve. Checking a guess takes one pass. Finding an answer may mean trying every set, and the number of sets doubles with each new number.

Play this lesson

How it works

  1. to check a guess: add it up, compare with the target
  2. to find one: try every set
  3. with n numbers there are 2ⁿ sets
  4. each new number doubles the work
  • Checking a guessFast
  • Finding an answerMaybe not
  • Sets of n numbers2ⁿ

Doubling sets

You need Paper and a pencil · Time 10 minutes

  1. List all the sets you can make from the numbers {1}: there are 2 (empty, and {1}).
  2. Now from {1, 2}: 4 sets. From {1, 2, 3}: 8. List them all.
  3. Check a guess like {1, 3} with one addition. How many sets would you list for 20 numbers?

Think about it. If a computer could check a billion sets a second, how long would 60 numbers take?
