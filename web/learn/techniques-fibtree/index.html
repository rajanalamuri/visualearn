Recursion: the call tree

Builder · ages 10+

Each Fibonacci number is the two before it added together. Written as recursion, every call makes two more calls, and the same small questions get asked again and again. The tree of calls shows the waste.

Play this lesson

How it works

  1. fib(n):
  2. if n is 0 or 1: answer n (the base case)
  3. otherwise: ask fib(n − 1) and fib(n − 2)
  4. add the two answers
  5. give the sum back
  • CallsGrow very fast
  • RepeatsThe same fib asked many times
  • FixRemember answers (DP)

Try it on paper

Recursion: the call tree Builder

Draw the calls

You need Paper and a pencil · Time 15 minutes

  1. Draw fib(5) at the top. Under it draw its two calls, fib(4) and fib(3). Keep drawing each call's two calls until you reach fib(1) or fib(0).
  2. Count the circles. How many say fib(2)? How many say fib(3)?
  3. Write the answer in each circle from the bottom up.
  4. Now think: how could you avoid answering fib(2) more than once?

Think about it. If fib(5) needs 15 calls, roughly how many would fib(10) need? What would writing answers down save?
