Pattern matching

Builder · ages 10+

To find a short word inside a long text, slide the word along one place at a time. At each place, compare letter by letter and stop at the first mismatch.

Play this lesson

How it works

  1. for each starting place in the text
  2. compare the word with the text, letter by letter
  3. if a letter differs: slide on
  4. if every letter matches: found here
  5. no more places to try
  • Worst caseO(text × word)
  • Simple?Very
  • Wasteful whenLots of near-matches

Try it on paper

Pattern matching Builder

Slide the word

You need A strip of paper with a short word, and a longer text on paper · Time 10 minutes

  1. Write a text of 12 letters from A, B and C. Write a pattern of 3 letters on a paper strip.
  2. Place the strip under the start of the text. Do all three letters match? Tick or cross.
  3. Slide the strip one place right and repeat until the end.
  4. Mark every place where all three letters matched.

Think about it. How many comparisons would you need to find a 100-letter pattern in a million-letter text, if every place nearly matched?
