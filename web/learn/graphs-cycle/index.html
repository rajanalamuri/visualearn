Cycle detection in graphs

Builder · ages 10+

Walk the graph depth-first. If you meet a dot you have already visited, and it is not the one you just came from, you have found a way round: a cycle.

Play this lesson

How it works

  1. visit a dot, remember where we came from
  2. for each neighbour
  3. if it is the dot we came from: ignore
  4. if it was already visited: a cycle!
  5. else visit it
  6. no repeat found: no cycle
  • TimeO(dots + lines)
  • Cycle meansA way back to the start
  • TreeHas no cycle

Cycle detection in graphs Builder

Find the loop

You need A drawing of 6 dots and 5 or 6 lines, and a pencil · Time 10 minutes

  1. Draw 6 dots joined by 5 lines so every dot is reachable. Walk from dot A, marking each dot you reach.
  2. Add one more line between two dots that are already joined by a path.
  3. Walk again. When a line leads to a marked dot (that you did not just come from), you have found the loop.

Think about it. Why does a connected graph with n dots and n − 1 lines never have a cycle?
