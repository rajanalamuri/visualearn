Linked lists: reverse

Builder · ages 10+

A linked list is a chain of boxes, each knowing only the next one. To reverse it, walk along and turn each arrow around to point at the box behind it.

Play this lesson

How it works

  1. previous ← nothing; current ← head
  2. while current exists
  3. next ← current.next (remember it!)
  4. current.next ← previous
  5. previous ← current; current ← next
  6. previous is the new head
  • TimeO(n)
  • Extra memoryO(1)
  • Each boxKnows only its next

Try it on paper

Linked lists: reverse Builder

Turn the arrows

You need 5 cards in a row and string or pencil arrows · Time 10 minutes

  1. Lay 5 cards in a row with an arrow from each card to the next.
  2. Start at the first card. Remember where its arrow pointed, then turn its arrow to point backward.
  3. Move to the card you remembered and repeat.
  4. When you finish, the chain runs the other way.

Think about it. What goes wrong if you turn an arrow before remembering where it pointed?
