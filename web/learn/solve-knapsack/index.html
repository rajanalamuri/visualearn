Knapsack

Advanced · ages 13+

A bag can only hold so much weight. Which items give the most value? Fill a table. For each item, either leave it, or take it and add its value to the best for the room that is left.

Play this lesson

How it works

  1. table[0][size] ← 0 (no items, no value)
  2. for each item i, each bag size s
  3. leave it: table[i−1][s]
  4. take it (if it fits): value + table[i−1][s − weight]
  5. table[i][s] ← the bigger of the two
  6. the answer is the last cell
  • Tableitems × bag sizes
  • TimeO(items × size)
  • MethodDynamic programming

Try it on paper

Knapsack Advanced

Pack the bag

You need Paper, a pencil and 4 items with weights and values · Time 20 minutes

  1. Pick 4 items, each with a weight (1 to 5) and a value. The bag holds weight 8.
  2. Draw a table: a row for each item added so far, a column for each bag size from 0 to 8.
  3. Fill row by row. For each cell compare "leave the item" (the cell above) and "take it" (its value plus the cell above and to the left by its weight).
  4. The last cell is the best value.

Think about it. Why does each cell only need to look at the row above?
