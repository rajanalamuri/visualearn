Heap sort

Builder · ages 10+

Turn the row into a heap with the biggest on top. Swap the top with the last place: that number is finished. Fix the heap and repeat until every number is finished.

Play this lesson

How it works

  1. build a max-heap (biggest on top)
  2. repeat:
  3. swap the top with the last unfinished place
  4. that place is now finished
  5. sift the new top down to rebuild the heap
  • TimeO(n log n)
  • Extra memoryNone
  • ComparesParent against children

Pyramid sort

You need Number cards (7) and a pyramid drawn on paper · Time 15 minutes

  1. Fill the pyramid with the cards, then fix it so every card is bigger than the cards below it.
  2. Swap the top card with the last card in the pyramid. Set that card aside: it is the biggest.
  3. Sink the new top card down until the pyramid is in order again.
  4. Keep going. The cards you set aside, read backward, are sorted.

Think about it. Why is the biggest card always on top of a max-heap?
