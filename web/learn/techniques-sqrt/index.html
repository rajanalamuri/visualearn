Sqrt decomposition

Advanced · ages 13+

Cut a long row into blocks and write down each block's total. To add up a stretch, use the written totals for whole blocks and add the few loose numbers at the ends.

Sqrt decomposition Advanced

Chunked sums

You need Paper with 9 numbers in three boxes of three · Time 10 minutes

  1. Write 9 numbers. Draw a box round each group of 3 and write the group total beneath it.
  2. Pick a stretch such as the 2nd to the 8th number.
  3. Add the loose numbers at each end one by one, and use the written total for any full box in between.
  4. Check with a slow sum.

Think about it. How many additions does this use compared with adding the whole stretch?
