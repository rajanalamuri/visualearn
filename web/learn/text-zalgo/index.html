Z-algorithm

Advanced · ages 13+

For each place in a word, the Z-number says how many letters from there match the start of the word. Remembering the longest match so far saves comparing the same letters again.

Play this lesson

How it works

  1. Z[0] ← the whole word (skip it)
  2. keep the window [l, r] of the furthest match
  3. for each position i
  4. inside the window: start from a known value
  5. extend by comparing letters
  6. grow the window if we passed r
  • TimeO(length)
  • Z[i]Match length with the start
  • Used forPattern search

Try it on paper

Z-algorithm Advanced

How much matches the start?

You need A short word on paper · Time 10 minutes

  1. Write the word AABXAAB. For each position, count how many letters in a row match the beginning of the word.
  2. Position 2 (A) matches AAB... count it.
  3. Write all the counts in a row. That is the Z row.

Think about it. What does a Z-value equal to the length of the pattern tell you if you search "pattern + # + text"?
