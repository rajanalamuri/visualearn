Amortised cost

Builder · ages 10+

A growing list lives in a box with spare room. Adding is cheap until the box is full. Then everything is copied into a box twice as big. That copy is rare, so adding stays cheap on average.

Play this lesson

How it works

  1. if the box is full:
  2. make a box twice as big
  3. copy everything across
  4. put the new item in
  5. average cost = total work ÷ adds
  • One addUsually 1 step
  • Average addUnder 3 steps
  • TrickDouble when full

Amortised cost Builder

The doubling shelf

You need Paper cups and small objects · Time 10 minutes

  1. Start with a row of 1 cup. Put an object in.
  2. When the row is full and you want to add another, lay out a row twice as long and carry every object across. Count each carry.
  3. Add 9 objects in all. Count every placement and every carry.
  4. Divide the total by 9.

Think about it. Why is it better to double the space than to add just one more cup each time?
