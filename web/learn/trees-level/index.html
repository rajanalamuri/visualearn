Level order traversal

Builder · ages 10+

Visit the tree row by row, top to bottom, left to right, using a queue. Good for finding the nearest node.

Play this lesson

How it works

  1. queue ← [root]
  2. take the front node and visit it
  3. add its children at the back
  • OrderRow by row
  • TimeO(n)
  • Each nodeVisited once

Level order traversal Builder

Walk the tree

You need A tree drawn on paper with 7 numbers, and a finger · Time 10 minutes

  1. Draw a tree with 7 numbers: one at the top, and up to two below each.
  2. Follow the rule: row by row. Say each number out loud as you "visit" it.
  3. Write the numbers in the order you said them.
  4. Try the other three orders on the same tree. Are the lists the same?

Think about it. Which order gives a sorted list on a search tree?
