Quick sort

Builder · ages 10+

Pick one number as the pivot. Put everything smaller on its left, and the pivot lands in its final spot. Then do the same on each side.

Play this lesson

How it works

  1. quickSort(lo, hi)
  2. if lo ≥ hi: return
  3. pivot ← a[hi]; i ← lo
  4. for j = lo … hi−1
  5. if a[j] < pivot: swap a[i], a[j]; i ← i+1
  6. swap a[i], a[hi] // pivot placed
  7. quickSort(lo, i−1); quickSort(i+1, hi)
  • Best caseO(n log n)
  • Worst caseO(n²)
  • Keeps equal items in order?No

The pivot game

You need 8 to 10 playing cards · Time 10 minutes

  1. Mix the cards and pick the last one as the pivot. Put it in the middle of the table.
  2. Every card smaller than the pivot goes in a pile on its left. Every other card goes on its right.
  3. The pivot is now in its final place. Leave it there.
  4. Play the same game with the left pile, then the right pile, until every pile has one card.

Think about it. What happens if the pivot is always the biggest card? Try it, and count how many times you compare.
