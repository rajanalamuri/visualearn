Suffix arrays

Advanced · ages 13+

Write every ending of a word and sort them like a dictionary. Words that start the same end up next to each other, so you can find them fast.

Play this lesson

How it works

  1. list every suffix of the word
  2. sort the suffixes alphabetically
  3. to find a pattern: binary search the sorted list
  4. compare the pattern with the start of the middle suffix
  5. all suffixes starting with the pattern are the matches
  • StoresSorted suffix starts
  • SearchO(pattern × log n)
  • Used forText search, DNA

Try it on paper

Suffix arrays Advanced

Sorted endings

You need A short word like BANANA, paper and a pencil · Time 15 minutes

  1. Write BANANA. Underneath write each ending: BANANA, ANANA, NANA, ANA, NA, A. Number them by where they start.
  2. Sort them like a dictionary: A, ANA, ANANA, BANANA, NA, NANA.
  3. To find ANA, look in the sorted list. All the endings that start with ANA are next to each other.
  4. The numbers beside them are where ANA occurs.

Think about it. Why are all the endings that start with the same pattern next to each other?
