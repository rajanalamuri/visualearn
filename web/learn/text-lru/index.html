Caches (LRU)

Builder · ages 10+

A cache is a small, fast shelf for things you use a lot. When it is full, throw out the thing you used longest ago. Every time you use something, move it to the front.

Play this lesson

How it works

  1. cache holds 3 items, ordered by last use
  2. item asked for:
  3. in the cache (a hit): move it to the newest end
  4. not there (a miss): fetch it
  5. if full: remove the oldest
  6. add it at the newest end
  • EvictsLeast recently used
  • HitItem already there
  • MissMust fetch it

The small desk

You need 3 spaces on a desk, and cards A to D · Time 10 minutes

  1. A desk fits only 3 cards. Someone asks for cards in a list like A B C A D B.
  2. If the card is on the desk, slide it to the newest end. If not, fetch it. If the desk is full, send away the card that has been there untouched the longest.
  3. Count hits (already on the desk) and misses.

Think about it. Why is "least recently used" a good guess for what you will not need next?
