Bit tricks: counting 1s

Builder · ages 10+

Computers store numbers as bits. Subtracting 1 flips the last 1 bit to 0. So n AND (n minus 1) removes exactly one 1 bit. Count how many times until you reach 0.

Play this lesson

How it works

  1. count ← 0
  2. while n is not 0
  3. n ← n AND (n − 1) (removes the lowest 1)
  4. count ← count + 1
  5. count is the number of 1-bits
  • Trickn AND (n − 1)
  • TimeOne step per 1-bit
  • Used forFast counting and checks

Bit tricks: counting 1s Builder

Flip the last 1

You need Paper and a pencil · Time 10 minutes

  1. Write a number in binary, like 10110100.
  2. Subtract 1 in binary. Notice the lowest 1 becomes 0 and the zeros after it become 1s.
  3. Line up the old and new numbers and keep a 1 only where both have a 1 (AND). The lowest 1 has vanished.
  4. Repeat until you reach 0. Count the repeats.

Think about it. Why does this loop run once per 1-bit and not once per bit?
