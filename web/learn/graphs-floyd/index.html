All-pairs shortest paths (Floyd-Warshall)

Advanced · ages 13+

Make a table of the shortest way between every pair of towns. Try each town as a stop-over, one at a time. If going through it is shorter, update the table.

Play this lesson

How it works

  1. table[i][j] ← direct road, or ∞
  2. for each stop-over town k
  3. for each pair i, j:
  4. if table[i][k] + table[k][j] < table[i][j]:
  5. table[i][j] ← that sum
  6. table holds every shortest distance
  • AnswersEvery pair at once
  • TimeO(towns³)
  • IdeaAllow one more stop-over

Try it on paper

All-pairs shortest paths (Floyd-Warshall) Advanced

The distance table

You need Paper (a 4 by 4 grid) and a small map · Time 20 minutes

  1. Draw 4 towns with one-way roads. Fill a 4 by 4 table with the direct road lengths, ∞ where there is none, 0 on the diagonal.
  2. Pick town A as the stop-over. For every cell, check: is (row to A) + (A to column) smaller? If so, write it in.
  3. Repeat with B, then C, then D as the stop-over.
  4. The table now holds the shortest distance between every pair.

Think about it. Why does the order of the stop-over towns not matter, as long as you use each once?
