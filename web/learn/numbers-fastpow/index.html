Fast powers

Builder · ages 10+

You do not need 12 multiplications to work out 3 to the power 13. Write the power in binary. Square your answer for every bit, and also multiply by 3 when the bit is 1.

Play this lesson

How it works

  1. result ← 1
  2. for each bit of the power, from the left
  3. square the result (keep the remainder)
  4. if the bit is 1: multiply by the base
  5. result is base^power
  • StepsAbout log₂ of the power
  • IdeaSquare, and sometimes multiply
  • Used forCodes and security

Fast powers Builder

Square and multiply

You need Paper and a calculator (optional) · Time 15 minutes

  1. Write 13 in binary: 1101.
  2. Start with 1. For the first bit (1): square, then multiply by 3. That gives 3.
  3. Next bit (1): square → 9, multiply by 3 → 27. Next bit (0): just square → 729. Last bit (1): square, then multiply by 3.
  4. Count the multiplications and compare with 12.

Think about it. How many multiplications does a power of one million need this way?
