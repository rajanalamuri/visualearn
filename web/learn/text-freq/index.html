Counting with hashes

Starter · ages 8+

A hash map is like a notebook where you find things by name straight away. Look up each letter and add 1 to its tally. Then the first letter with a tally of 1 is the first that never repeats.

Play this lesson

How it works

  1. counts ← an empty hash map
  2. for each letter: counts[letter] ← counts[letter] + 1
  3. for each letter in order
  4. if counts[letter] is 1: that is the answer
  5. every letter repeats: no answer
  • Look-upAbout 1 step
  • TimeO(length)
  • Instead ofRescanning for each letter

Try it on paper

Counting with hashes Starter

Tally the letters

You need A word on paper and a pencil · Time 10 minutes

  1. Write a word like SWISS... a longer one, like LETTERS.
  2. Make a list of letters and a tally column. For each letter in the word, find its row and add a tally.
  3. Now read the word again from the start. The first letter with a tally of 1 is the first letter that never repeats.

Think about it. Why is it better to keep a tally than to count the letter again every time you meet it?
