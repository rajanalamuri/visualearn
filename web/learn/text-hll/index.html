HyperLogLog

Advanced · ages 13+

How many different things went past? Scramble each one into bits and count the zeros at the start. Seeing a long run of zeros is rare, so a long run means a big crowd. One small counter gives a rough answer.

Play this lesson

How it works

  1. best ← 0
  2. for each item: scramble it into 8 bits
  3. count the zeros at the start
  4. best ← the larger of best and that count
  5. estimate ← 2 to the power (best + 1)
  • MemoryOne tiny counter
  • Estimate2 to the power (zeros + 1)

HyperLogLog Advanced

Rare coin runs

You need A coin · Time 10 minutes

  1. Flip a coin until you get heads. Count the tails first (these are like leading zeros). Do it 8 times and write the biggest count.
  2. Now do it 32 times. Does the biggest count go up?
  3. The more people flipping, the longer the longest run. So the longest run tells you roughly how many flipped.

Think about it. Why does one very rare value suggest a big crowd rather than a lucky few?
