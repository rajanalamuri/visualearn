Network flow

Advanced · ages 13+

Pipes have limits. How much can flow from the start S to the end T? Find a route with room, push as much as fits, and repeat. When no route is left, you have found the most.

Play this lesson

How it works

  1. flow ← 0
  2. find a route S → T where every pipe has spare room
  3. push as much as the tightest pipe allows
  4. add it to the flow; use up that room
  5. no route left: the flow is the most possible
  • FindsThe biggest flow
  • MethodKeep finding routes with room
  • TimeO(V·E²)

Try it on paper

Network flow Advanced

Pipes and buckets

You need Paper, a pencil and a drawing of 6 dots joined by arrows with limits · Time 20 minutes

  1. Draw S, A, B, C, T with arrows and write a limit on each arrow.
  2. Find a route from S to T. The most you can send is the smallest limit along it. Write that flow on each arrow and subtract it from the limits.
  3. Find another route using the room that is left. Repeat until none exists.
  4. Add up everything you sent.

Think about it. Why can the flow never be more than the total limit of the pipes leaving S?
