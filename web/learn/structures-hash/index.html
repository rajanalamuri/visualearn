Hash tables

Starter · ages 8+

A hash table does not search at all. A tiny rule, here the remainder after dividing, tells you which shelf a number lives on. To find it later, use the same rule and look on just that shelf.

How it works

  1. shelf ← number mod 7
  2. put the number on that shelf
  3. to find: shelf ← number mod 7
  4. check only the numbers on that shelf

The seven-shelf shop

You need Paper, a pencil and 8 numbers between 10 and 99 · Time 10 minutes

  1. Draw seven boxes in a row and write 0 to 6 above them. These are your shelves.
  2. Take a number. Divide it by 7 and write the remainder in your head. Write the number in that box.
  3. If the box already has numbers, write the new one beside them.
  4. When all eight are filed, ask a friend to pick one. Find it by checking only one box.

Think about it. Two numbers landed on the same shelf. Is that a mistake, or just something the table has to cope with? What if all eight landed on one shelf?
