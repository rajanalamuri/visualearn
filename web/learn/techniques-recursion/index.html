Recursion

Starter · ages 8+

A function can solve a problem by calling itself on a smaller version. 5! is 5 times 4!, and so on down to 1!, which is just 1. That smallest case is the base case. Then each waiting call finishes on the way back up.

Play this lesson

How it works

  1. factorial(n):
  2. if n is 1: answer 1 (the base case)
  3. otherwise: ask factorial(n − 1)
  4. when it answers: multiply by n
  5. give that answer back
  • NeedsA base case
  • Each callA smaller problem
  • RemembersA stack of waiting calls

Try it on paper

Recursion Starter

Russian dolls

You need A set of nesting dolls (or 5 cups that stack), paper and a pencil · Time 10 minutes

  1. Open the biggest doll. Inside is a smaller one: open that. Keep going until the smallest, which holds nothing. That is the base case.
  2. Now close them back up from the smallest. Each time, you finish the job for that doll.
  3. Write 5! as 5 × 4!, 4! as 4 × 3!, and so on down to 1. Then work back up multiplying.
  4. Notice you needed to remember every unfinished doll on the way down.

Think about it. What would happen if the dolls never ended, with no smallest one?
