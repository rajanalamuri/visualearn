Topological sort

Builder · ages 10+

Some jobs must wait for others. Count how many things each job is waiting for. Do any job that is waiting for nothing, then tell the jobs after it that one wait is over. Repeat.

Play this lesson

How it works

  1. count what each job is waiting for
  2. queue every job waiting for nothing
  3. take a job from the queue and do it
  4. for each job after it: its count goes down by one
  5. if a count reaches 0: add it to the queue
  6. order done = a valid order
  • NeedsNo loops
  • TimeO(jobs + links)
  • ResultA valid order

Try it on paper

Topological sort Builder

Getting ready

You need Cards for 6 jobs, and arrows drawn between them · Time 15 minutes

  1. Write jobs on cards: Wake, Wash, Dress, Eat, Pack, Go. Draw an arrow from each job to one that must come after it.
  2. Next to each card write how many arrows point into it.
  3. Do a card with 0, write the order down, and cross out the arrows leaving it.
  4. Repeat until all cards are done.

Think about it. Can there be more than one valid order? What if two jobs wait for each other?
