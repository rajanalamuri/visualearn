Roadmap · Hashing and text

Compression (Huffman)

Builder · ages 10+

Give common letters short codes and rare letters long ones. Keep joining the two rarest items into one. The joins form a tree, and the path to each letter is its code of 0s and 1s.

Play this lesson

How it works

  1. put every letter in the queue with its count
  2. take the two smallest items
  3. join them into one item (add their counts)
  4. put it back; repeat until one item is left
  5. left branch = 0, right branch = 1
  • IdeaShort codes for common letters
  • MethodJoin the two smallest
  • ResultFewest bits possible

Try it on paper

Compression (Huffman) Builder

Make a code

You need Paper, a pencil and a short message · Time 20 minutes

  1. Write a short message and count each letter.
  2. Write each letter with its count. Cross out the two smallest and replace them with one item that has their total.
  3. Repeat until one item is left. You have drawn a tree.
  4. Label left branches 0 and right branches 1. Each letter's code is the path from the top to it.

Think about it. Why does giving the common letters shorter codes make the whole message shorter?
