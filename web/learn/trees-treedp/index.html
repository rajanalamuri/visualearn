Roadmap · Trees

Tree DP

Advanced · ages 13+

Pick nodes in a tree to get the most total value, but never two nodes that are joined. For each node work out the best total if you take it and if you skip it, using what its children already found.

Play this lesson

How it works

  1. for each node, children first
  2. take it: its value + each child's skip total
  3. skip it: each child's better of take and skip
  4. the answer is the bigger of the root's two totals
  • OrderChildren first
  • Per nodeTake or skip
  • TimeO(nodes)

Try it on paper

Tree DP Advanced

Pick without neighbours

You need A tree of 7 circles on paper, each with a value · Time 15 minutes

  1. Draw a tree and write a value in each circle.
  2. Work from the bottom up. Beside each circle write two numbers: best if I take it, best if I skip it.
  3. Take = its value + the skip numbers of its children. Skip = the bigger of each child's two numbers, added up.
  4. The bigger of the top circle's two numbers is your answer.

Think about it. Why can a child's answer be reused, instead of being worked out again?
