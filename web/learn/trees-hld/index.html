Heavy-light decomposition

Advanced · ages 13+

Split a tree into long chains by always going down to the child with the biggest subtree. Any path then crosses only a few chains, because each time you leave a chain the tree at least doubles.

Play this lesson

How it works

  1. size[node] ← 1 + the sizes of its children
  2. heavy child ← the child with the biggest size
  3. a heavy child continues its parent's chain
  4. every other child starts a new chain
  5. path query: while the chains differ, jump the deeper chain's head to its parent
  • Heavy childBiggest subtree
  • Chains crossedAt most about log n
  • Used forFast path queries

Try it on paper

Heavy-light decomposition Advanced

Chains in a tree

You need A tree of 9 circles on paper and coloured pencils · Time 20 minutes

  1. Draw a tree of 9 circles. Write beside each circle the size of the tree hanging below it (itself included).
  2. From each circle, draw a thick line to the child with the larger size. Thin lines go to the others.
  3. Colour each chain of thick lines in one colour. Every circle belongs to exactly one chain.
  4. Pick two circles. Count how many times a path between them switches colour.

Think about it. Why does the subtree at least double each time you take a thin line upward?
