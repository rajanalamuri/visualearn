Longest common subsequence

Advanced · ages 13+

Two words can share letters in the same order, even if the letters are not side by side. Fill a table. If two letters match, add 1 to the cell up-left. If not, copy the bigger of the cell above and the cell to the left.

Play this lesson

How it works

  1. table[0][·] and table[·][0] are 0
  2. for each letter pair (i, j)
  3. if the letters match: table[i][j] ← table[i−1][j−1] + 1
  4. else: table[i][j] ← the bigger of the cell above and the cell to the left
  5. the last cell is the length
  • ComparesTwo sequences
  • TimeO(m × n)
  • Used forFile diffs, DNA

Try it on paper

Longest common subsequence Advanced

Shared letters

You need Two short words on paper and a grid · Time 15 minutes

  1. Write one word across the top and one down the side of a grid. Fill the first row and column with 0.
  2. For each cell: if the two letters match, write one more than the cell up and to the left.
  3. If not, write the bigger of the cell above and the cell to the left.
  4. The bottom-right number is the length of the longest shared sequence.

Think about it. Is a shared sequence allowed to skip letters? Is it allowed to reorder them?
