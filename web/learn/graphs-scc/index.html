Strongly connected components

Advanced · ages 13+

On one-way roads, a strongly connected group is a set of towns where you can get from any town to any other. Search once to see which towns finish first. Then search the roads backwards, starting from the last one.

Play this lesson

How it works

  1. pass 1: depth-first search, note the order towns finish
  2. reverse every road
  3. pass 2: take towns in reverse finish order
  4. search the reversed roads from it
  5. everything reached is one group

Try it on paper

Strongly connected components Advanced

One-way streets

You need Paper, a pencil and a drawing of 7 towns with one-way arrows · Time 20 minutes

  1. Draw 7 towns and some one-way arrows.
  2. Pass 1: walk depth-first from any town. Write each town down at the moment you have finished with it.
  3. Redraw every arrow backward. Pass 2: take the town you wrote last. Walk along the backward arrows to everything you can reach that is not yet coloured. That is one group.
  4. Repeat with the next-latest uncoloured town.

Think about it. Can two different groups ever reach each other in both directions?
