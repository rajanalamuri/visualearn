Bridges and cut points

Advanced · ages 13+

A bridge is a road that splits the network if you close it. Walk depth-first and note when you reach each town and the earliest town it can get back to. If a town cannot get back past its parent, the road to it is a bridge.

Play this lesson

How it works

  1. disc[u] ← the time we first reach u; low[u] ← disc[u]
  2. for each road u – v (not the one we came by)
  3. new town: search it, then low[u] ← min(low[u], low[v])
  4. if low[v] > disc[u]: the road is a bridge
  5. seen town: low[u] ← min(low[u], disc[v])

Bridges and cut points Advanced

Which road is a lifeline?

You need A drawing of 7 towns and 8 roads, and a pencil · Time 15 minutes

  1. Draw 7 towns joined by roads, with a couple of loops.
  2. For each road, imagine closing it. Can you still get from any town to any other? If not, it is a bridge.
  3. Notice that bridges are never part of a loop.

Think about it. Why can a road inside a loop never be a bridge?
