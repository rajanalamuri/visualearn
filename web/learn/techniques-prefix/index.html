Prefix sums

Builder · ages 10+

Add up the row once, keeping a running total. After that, the sum of any stretch is just one subtraction: the total at the end minus the total just before the start.

Play this lesson

How it works

  1. P[0] ← 0
  2. for each i: P[i+1] ← P[i] + a[i]
  3. sum of a[l..r] ← P[r+1] − P[l]
  • BuildO(n) once
  • Each questionO(1)
  • Instead ofRe-adding every time

Try it on paper

Prefix sums Builder

Running total

You need Paper and a pencil · Time 10 minutes

  1. Write 8 numbers in a row. Under them, write a running total: each box is the box before plus the number above.
  2. Pick two positions. The sum between them is the running total at the end minus the running total just before the start.
  3. Check by adding the numbers one by one. They agree.

Think about it. If you had to answer 1000 questions about the same row, why is the running total worth building first?
