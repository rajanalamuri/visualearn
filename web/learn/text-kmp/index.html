Roadmap · Hashing and text

KMP (prefix table)

Advanced · ages 13+

When a letter does not match, you already know the letters before it matched. A table made from the word tells you how far back to restart, so you never move back in the text.

Play this lesson

How it works

  1. table[i] ← length of the longest start of the word that is also an end of its first i+1 letters
  2. for each letter of the text
  3. while the word letter differs: fall back using the table
  4. if it matches: move on in the word
  5. if the whole word matched: found
  • TimeO(text + word)
  • Text pointerNever goes back
  • NeedsA prefix table

Try it on paper

KMP (prefix table) Advanced

Slide smartly

You need A paper strip with the word ABAB, and a text of 12 letters from A and B · Time 20 minutes

  1. Build the table for ABAB. Position 3 (AB) is 0, position 3 (ABA) is 1 because A starts and ends it, position 4 (ABAB) is 2 (AB).
  2. Match the word along the text. When a mismatch happens, do not slide back: restart in the word at the table value.
  3. Mark every place where the word fully matches.

Think about it. Why can the text pointer never move backward?
