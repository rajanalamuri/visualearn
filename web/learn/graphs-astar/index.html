A* search

Advanced · ages 13+

Like breadth-first search, but it has a nose for the goal. Score each square by the steps so far plus a guess of the steps left. Always explore the square with the lowest score.

Play this lesson

How it works

  1. open ← [start]
  2. take the open square with the smallest f = g + h
  3. if it is the goal: stop
  4. for each neighbour: g ← g + 1, f ← g + h
  5. add it to the open list
  6. follow the way back to draw the path
  • FindsShortest path
  • NeedsA guess that never over-estimates
  • Faster thanBlind searching

Try it on paper

A* search Advanced

Guided walk

You need Squared paper, a pencil and a pair of coloured pencils · Time 15 minutes

  1. Draw a 5 by 7 grid. Shade a few walls. Mark start (top left) and goal (bottom right).
  2. For a square, g is the steps you have walked to reach it. h is the number of squares across plus down to the goal, ignoring walls.
  3. Write f = g + h in each square you reach. Always continue from the open square with the smallest f.
  4. When you reach the goal, trace the way back.

Think about it. Why does the guess h help, and what would happen if h were always 0?
