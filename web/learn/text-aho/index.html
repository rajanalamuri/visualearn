Search a text for many words at once. Build a trie of the words and give each node a fall-back link. Then read the text one time and never go back.

Play this lesson

How it works

  1. build a trie of all the words
  2. fail link of a node ← the longest shorter ending that is also a start in the trie
  3. for each letter of the text
  4. while no branch for the letter: follow the fail link
  5. step along the branch, then report every word that ends here (following fail links)

Aho-Corasick Advanced

Many words, one pass

You need Paper, a pencil, a few short words and a text · Time 25 minutes

  1. Draw a trie for the words HE, SHE, HIS and HERS.
  2. For each node, work out where to fall back to if the next letter fails: the longest ending of what you have matched that is also a start of some word.
  3. Read the text USHERS one letter at a time, moving along the trie or falling back.
  4. Every time you reach a node where a word ends (or a fall-back chain through one), note the word.

Think about it. Why does reading "SHE" also find "HE"?
