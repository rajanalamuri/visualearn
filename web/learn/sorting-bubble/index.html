Bubble sort

Starter · ages 8+

Walk along the list and swap any two neighbours that are in the wrong order. Each walk carries the biggest number left to the end, like a bubble rising.

Play this lesson

How it works

  1. for each pass i = 0, 1, …
  2. swapped ← false
  3. for j = 0 … n−2−i
  4. if a[j] > a[j+1]
  5. swap a[j], a[j+1]; swapped ← true
  6. a[n−1−i] is in place
  7. if not swapped: stop
  • Best caseO(n)
  • Worst caseO(n²)
  • Keeps equal items in order?Yes

Bubble sort Starter

The bubble line-up

You need 4 to 8 people, or 8 playing cards · Time 10 minutes

  1. Stand in a line in any order.
  2. Start at the left end. Look at the first two people. If the taller one is on the left, they swap places.
  3. Take one step right and check the next two. Keep going to the end of the line.
  4. The tallest person is now at the right end. They are sorted, so they can sit down.
  5. Start again from the left. You are done when you walk the whole line and nobody swaps.

Think about it. How many times did the shortest person move? Why do small values travel left so slowly?
