Bloom filters

Advanced · ages 13+

A Bloom filter remembers words using a tiny row of bits. Each word switches on three bits. If any of a word's bits is off, it was definitely not added. If all are on, it was probably added.

Play this lesson

How it works

  1. start with 16 bits, all 0
  2. add: switch on the 3 bits the word points to
  3. ask: look at the word's 3 bits
  4. any bit is 0: definitely not added
  5. all bits 1: probably added
  • MemoryTiny
  • "No" meansDefinitely no
  • "Yes" meansProbably yes

Try it on paper

Bloom filters Advanced

Bit board

You need 16 small squares on paper (or coins), and some words · Time 15 minutes

  1. Draw a row of 16 boxes, all empty. Make up a rule that gives each word three box numbers (like adding letter positions).
  2. To add a word, fill its three boxes.
  3. To ask about a new word, look at its three boxes. Any empty box means it was never added.
  4. If all three are filled you can only say "probably".

Think about it. Can a Bloom filter ever say "no" about a word that was added? Why not?
