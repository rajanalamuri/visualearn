LearnPlayRoadmap

For teachers and parents

108 short visual lessons on how computers think. Children guess first, watch it happen, then do a paper activity.

Run it in 45 minutes

  1. 10 min, together. Project one lesson. The class votes on each "guess first" question before the answer shows.
  2. 25 min, in groups. Hand out the printed paper activity for that lesson.
  3. 10 min, share. Compare what each group found, and talk about the "think about it" question.

Print the activities Starter path (8+) Builder (10+) Advanced (13+)

What you can rely on

  • Every lesson's answers are checked by automated tests against independent reference code.
  • The lesson explanations are written at about a grade 4 to 5 reading level.
  • Pages you have already opened keep working without a connection.
  • No ads, no tracking, and no email or password for children.

What we do not know yet

This has not been through a classroom trial. If you try it with a class, tell us what happened.

Screen time and privacy

A grown-up can set a daily limit on the home page. Progress stays on the device. Read the privacy page.
